# Поликлиника №40

Система управления поликлиникой на Windows Forms (.NET Framework 4.8) с базой данных SQLite.

## Установка и запуск

### Требования
- Visual Studio 2017 или новее
- .NET Framework 4.8
- Windows 7 или новее

### Шаги по установке

1. Клонируйте репозиторий или скачайте ZIP-архив
2. Откройте файл `Poli40.slnx` в Visual Studio
3. Установите пакет SQLite через NuGet:
4. Настройте проект (в свойствах):
- **Сборка → Целевая платформа:** `x86`
- **События сборки → После сборки:**. Нажмите `F5` или `Build → Rebuild Solution` для запуска

## Руководство пользователя

### Администратор
- **Просмотр данных:** на главном экране отображаются списки пациентов, врачей и записей
- **Добавить пациента:** нажмите «Добавить пациента» → заполните все поля → «Сохранить»
- **Удалить пациента:** выберите пациента из списка → «Удалить пациента» → подтвердите
- **Добавить врача:** нажмите «Добавить врача» → заполните поля (логин и пароль обязательны) → «Сохранить»
- **Удалить врача:** выберите врача из списка → «Удалить врача» → подтвердите
- **Обновить:** нажмите «Обновить» для актуализации всех списков

### Врач
- **Просмотр расписания:** выберите дату — отобразится список пациентов на этот день
- **Изменить статус приёма:**
- «Был на приёме» — пациент обслужен
- «Отменён» — запись отменена
- «Не явился» — пациент не пришёл
- Выберите запись в списке, затем нажмите нужную кнопку статуса

### Пациент
- **Запись на приём:**
1. Выберите врача из списка слева
2. Укажите дату и время
3. Нажмите «Записаться»
- **Отмена записи:**
1. Выберите свою запись в списке «Мои записи»
2. Нажмите «Отменить запись»
- **Регистрация нового пациента:**
1. На вкладке входа «Пациент» нажмите «Регистрация»
2. Заполните ФИО, пароль и ОМС (ровно 16 цифр)
3. Нажмите «Зарегистрироваться»

## Структура базы данных

База данных SQLite состоит из четырёх таблиц:

**Admins** — администраторы системы (Id, Login, Password, FullName)

**Doctors** — врачи поликлиники (Id, LastName, FirstName, MiddleName, Specialization, Office, Login, Password)

**Patients** — пациенты (Id, LastName, FirstName, MiddleName, BirthDate, OMS, Phone, Email, Address, Password)

**Appointments** — записи на приём (Id, PatientId, DoctorId, AppointmentDate, AppointmentTime, Status, CreatedAt)

## Функциональность

- Вход для администратора, врача и пациента
- Регистрация новых пациентов
- Запись пациентов к врачам
- Отмена записей пациентом
- Просмотр расписания врачом
- Изменение статуса приёма (завершён, отменён, неявка)
- Добавление и удаление врачей/пациентов администратором
- Хеширование паролей (SHA-256)
- Автоматическое создание базы при первом запуске

## Технологии

- C# (Windows Forms)
- .NET Framework 4.8
- SQLite (System.Data.SQLite.Core 1.0.118)
- SHA-256 для хеширования паролей
- NuGet Package Manager

## Примечания

- База данных создаётся автоматически при первом запуске
- При повторном запуске старая база удаляется и создаётся заново с тестовыми данными
- Для сохранения данных между запусками удалите вызов `File.Delete("Poli40.db")` в `Database.cs`
- Пароли хранятся в зашифрованном виде (SHA-256)
- Для корректной работы требуется платформа x86
- ОМС должен содержать ровно 16 цифр
